# MVP Система Полевой Инвентаризации

## Оригинальная Задача
MVP система полевой инвентаризации для ~40,000 объектов.

## Архитектура
- **Backend:** FastAPI + MongoDB (`/app/backend/server.py`)
- **Frontend:** React + Tailwind + Shadcn (`/app/frontend/src/`)

### ✅ Объекты с ОБЯЗАТЕЛЬНЫМИ полями
**Местоположение и ответственные:**
- **ОИВ** (oiv) - организация
- **ЭТАЖ** (floor) - номер этажа
- **УПРАВЛЕНИЕ** (management) - управление

- **МЕСТО/Помещение** (room) - кабинет/комната

Также: name, category, characteristics, serial_number, inventory_number, year, condition, quantity, notes

## API Endpoints

### Auth
- POST /api/auth/login - Вход (возвращает токен напрямую)
- POST /api/auth/register - Регистрация
- GET /api/auth/me - Текущий пользователь

### Objects
- GET /api/objects?sort=name_asc&category_id=xxx
- POST /api/objects
- PUT /api/objects/{id}

### Import
- POST /api/import/preview - предпросмотр файла
- POST /api/import/execute?mapping=JSON - импорт

### Export
- GET /api/export/document?doc_type=catalog&format=pdf
- GET /api/export/document?doc_type=catalog&format=xlsx

### References
- GET /api/references?type=floor
- POST /api/references
