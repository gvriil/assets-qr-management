# MVP Система Полевой Инвентаризации

## Оригинальная Задача
MVP система полевой инвентаризации для ~40,000 объектов.

## Архитектура
- **Backend:** FastAPI + MongoDB (`/app/backend/server.py`)
- **Frontend:** React + Tailwind + Shadcn (`/app/frontend/src/`)
- **URL:** https://assettracker-41.preview.emergentagent.com

## Реализовано (Февраль 2026)

### ✅ Аутентификация
- JWT авторизация (2FA ОТКЛЮЧЕНА)
- Прямой вход без кода подтверждения
- Тестовый админ: 0020992@gmail.com / admin123

### ✅ Объекты с ОБЯЗАТЕЛЬНЫМИ полями
- **ОИВ** - организация (с автозаполнением из справочников)
- **ЭТАЖ** - номер этажа (с автозаполнением)
- **УПРАВЛЕНИЕ** - управление (с автозаполнением)
- **ОТДЕЛ** - отдел (с автозаполнением)
- **МЕСТО/Помещение** - кабинет/комната
- **ФИО (МОЛ)** - материально-ответственное лицо (с автозаполнением из 42 записей)
- **QR код** - можно добавить/изменить в любой момент

### ✅ Справочники (наполнены из PDF)

## API Endpoints

### Auth
- POST /api/auth/login - Вход (токен сразу)
- GET /api/auth/me - Текущий пользователь

### Objects
- GET /api/objects
- POST /api/objects
- PUT /api/objects/{id}

### References
- GET /api/references
- GET /api/references?type=mol
- POST /api/references

### Export
- GET /api/export/document?doc_type=catalog&format=pdf

### QR
- GET /api/qr-batches
- POST /api/qr-batches
- GET /api/qr-batches/{id}/pdf
