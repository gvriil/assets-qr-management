# MVP Система Полевой Инвентаризации

## Оригинальная Задача
MVP система полевой инвентаризации для ~40,000 объектов с 15-20 полевыми исполнителями.
Полный цикл: загрузка Excel/CSV → генерация QR → печать → наклейка → сканирование → сопоставление/создание позиций → фото/история изменений → экспорт отчетов и каталогов.

## Архитектура

### Backend (FastAPI + MongoDB)
- `/app/backend/server.py` - основной сервер
- JWT аутентификация с 2FA
- RBAC: admin, operator, field_worker, auditor, mol
- REST API с prefix `/api`

### Frontend (React + Tailwind + Shadcn)
- `/app/frontend/src/` - исходники
- PWA для мобильных устройств
- QR сканер через html5-qrcode

## API Endpoints

### Export Documents (NEW)
- GET /api/export/document?doc_type=catalog&format=pdf - официальные документы
- doc_type: photo_archive, catalog, inventory_list, specification_report
- format: pdf, xlsx
- Параметры: status, room, commission (JSON)

### QR Batches
- POST /api/qr-batches - с label_data (ОИВ, этаж, и др.)
- GET /api/qr-batches/{id}/pdf
