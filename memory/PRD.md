# MVP Система Полевой Инвентаризации

## Описание
Система для полевой инвентаризации ~40,000 объектов с поддержкой QR-кодов, мобильного сканирования и экспорта отчетов.

## Архитектура
- **Backend:** FastAPI + MongoDB
- **Frontend:** React + Tailwind + Shadcn/UI
- **Развертывание:** Docker + Docker Compose + Nginx

## API Endpoints

### Auth
- POST /api/auth/login
- POST /api/auth/register
- GET /api/auth/me

### Objects
- GET/POST /api/objects
- PUT /api/objects/{id}
- POST /api/objects/{id}/verify
- POST /api/objects/{id}/photo
- DELETE /api/objects/{id}/photo

### References
- GET/POST /api/references

### Import
- POST /api/import/objects
- POST /api/import/references

### Export
- POST /api/export/documents

### QR
- GET/POST /api/qr-batches
- GET /api/qr-batches/{id}/pdf

### Users (Admin)
- GET /api/users
- PUT /api/users/{id}
- DELETE /api/users/{id}

### Health
- GET /api/health

## Переменные окружения

### Backend (.env)
- `MONGO_URL` - URL подключения к MongoDB
- `DB_NAME` - Имя базы данных
- `JWT_SECRET` - Секретный ключ для JWT (обязателен!)
- `CORS_ORIGINS` - Разрешенные origins

### Frontend (.env)
- `REACT_APP_BACKEND_URL` - URL бэкенда

## Известные проблемы
