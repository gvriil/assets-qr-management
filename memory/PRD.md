# MVP Система Полевой Инвентаризации

## Оригинальная Задача
MVP система полевой инвентаризации для ~40,000 объектов.

## Архитектура
- **Backend:** FastAPI + MongoDB (`/app/backend/server.py`)
- **Frontend:** React + Tailwind + Shadcn (`/app/frontend/src/`)

## Реализовано (Февраль 2026)

### ✅ Объекты с ОБЯЗАТЕЛЬНЫМИ полями
**Местоположение и ответственные:**
- **ОИВ** (oiv) - организация
- **ЭТАЖ** (floor) - номер этажа
- **УПРАВЛЕНИЕ** (management) - управление
- **ОТДЕЛ** (department) - отдел
- **МЕСТО/Помещение** (room) - кабинет/комната
- **ФИО (МОЛ)** (mol) - материально-ответственное лицо

Также: name, category, characteristics, serial_number, inventory_number, year, condition, quantity, notes

### ✅ Импорт с разбивкой по запятым
- **НОВОЕ:** Опция "Разбивать описание по запятым"
- Автоматическое извлечение: этаж, кабинет, год, серийный номер
- Остаток добавляется в характеристики и примечание
- Автоопределение строки заголовков в CSV
- Пропуск строк "Итого" и пустых строк
- Новые поля в маппинге: ОИВ, Управление, Место

### ✅ Сортировка и фильтрация объектов
- 7 опций сортировки
- Фильтрация по статусу и категории

## API Endpoints

### Objects
- GET /api/objects?sort=name_asc&category_id=xxx
- POST /api/objects
- PUT /api/objects/{id}

### Import
- POST /api/import/preview - предпросмотр файла
- POST /api/import/execute?mapping=JSON - импорт с опциями:
  - fillDownCategory: bool
  - skipEmptyRows: bool
  - parseCommas: bool (разбивка по запятым)
